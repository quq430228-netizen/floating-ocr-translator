# Windows 悬浮翻译窗（支持文字与截图 OCR）

与语音转文字悬浮窗采用一致的极简悬浮交互：平时收起为一个可随意拖动的绿色圆形「译」悬浮图标，点击后展开为占屏幕约 **1/16** 的圆角矩形卡片。

## 核心功能

- **粘贴文字极速翻译**：复制任意英文/外文文字后，点下方 **「粘贴翻译」** 或在窗口内按 **`Ctrl+V`**，秒出中文译文（免 API Key，默认走国内直连低延迟线路，多线路自动容错）。
- **截图 / 图片离线 OCR 翻译**：
  - 用微信 / QQ / 系统 `Win+Shift+S` 截图后，直接点 **「粘贴翻译」** 或按 **`Ctrl+V`**；
  - 或直接把图片拖进窗口 / 点击右上角 **图片图标** 选择本地图片；
  - 内置本地离线 **RapidOCR (ONNX Runtime)**，图片不上传服务器，自动提取文字并翻译。
- **查看原文与一键复制**：
  - 底部左侧 **「复制」** 一键复制译文到剪贴板；
  - 右上角 **「原」** 按钮可随时切换查看识别出的原文（支持修改后按 `Ctrl+Enter` 重译）；
  - 右键菜单支持开启 **「自动监听剪贴板翻译」** 和 **「智能中英互译」**。

## Windows 一键安装与启动

确保电脑已安装 **Python 3.10+**，在项目目录下运行以下命令即可自动创建虚拟环境、安装依赖、生成桌面快捷方式并启动翻译悬浮窗：

```powershell
powershell -ExecutionPolicy Bypass -File .\setup_windows.ps1
```

## 日常启动方式

双击桌面快捷方式 **「翻译悬浮窗」**，或双击本目录下的 **`启动翻译悬浮窗.vbs`** 即可无黑框静默启动。
